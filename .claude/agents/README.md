# 개발팀 에이전트 (Dev Team Agents)

Claude Code의 **서브에이전트(subagent)** 기능으로 구성한 가상 개발팀입니다.
각 `.md` 파일이 한 명의 팀원(역할)이며, 메인 Claude가 작업에 맞는 팀원을 호출합니다.

## 팀 구성

| 파일 | 역할 | 책임 |
|------|------|------|
| `pm.md` | PM | 요구사항 분해, 우선순위, 작업 분배 |
| `planner.md` | 기획자 | 유저 스토리, 기능 명세, 수용 기준 |
| `architect.md` | 설계자 | 아키텍처, 모듈 구조, 기술 선택 |
| `developer.md` | 개발자 | 실제 코드 작성/수정 |
| `qa.md` | QA | 테스트, 검증, 코드 리뷰 |

## 권장 워크플로우

```
요구사항
   │
   ▼
[PM] 작업 분해·우선순위
   │
   ▼
[기획자] 무엇을 만들지 명세
   │
   ▼
[설계자] 어떻게 만들지 설계
   │
   ▼
[개발자] 구현
   │
   ▼
[QA] 검증·리뷰  ──(문제 발견)──▶ 다시 개발자
   │
   ▼
 완료
```

## 사용법

그냥 평소처럼 Claude에게 요청하면, Claude가 필요한 팀원을 자동으로 호출합니다.
특정 팀원을 직접 지정하고 싶을 때는 이렇게 말하면 됩니다:

- "pm 에이전트로 이 요구사항을 작업으로 분해해줘"
- "planner를 시켜서 로그인 기능 명세를 만들어줘"
- "architect한테 설계를 맡기고, developer로 구현해줘"
- "qa로 방금 만든 코드를 검증해줘"

## 커스터마이즈

각 `.md` 파일의 `tools:` 항목으로 팀원이 쓸 수 있는 도구를 제한할 수 있고,
본문(시스템 프롬프트)을 수정해 역할의 행동 방식을 바꿀 수 있습니다.
- 도구를 제한하면 안전하지만 할 수 있는 일이 줄어듭니다.
- `tools:` 줄을 지우면 모든 도구를 상속받습니다.
